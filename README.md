## O que este programa faz:
Este programa pega uma planilha (**.csv**) de preços, mostra seus dados na tela, aplica o desconto<br>
que você desejar e após aplicar o desconto, reescreve os antigos valores pelos novos e escreve uma nova<br>
planilha **.csv** e joga para a pasta de documentos.

## Como rodar o programa:
Antes de compilá-lo, peço que use uma planilha de teste contendo as colunas: produto e preço, para que o teste funcione <br>
Após compilar ele na sua máquina, ele primeiro irá pedir para que você insira o caminho do arquivo válido,<br>
ou seja: /home/nome-usuario/nome-do-arquivo.csv, isso tudo dependerá de qual sistema operacional você usa,<br>
após colocar o arquivo (de preferência **.csv**), ele irá pedir para que você digite o desconto que você desejar<br>
Digitando-o você pode clicar no botão de **"Calcular Preço"**, ele irá fazer todo o cálculo, escrever em um novo arquivo<br>
e jogar na sua pasta de **Documentos**.
