## O que este programa faz:
Este programa pega uma planilha (**.csv**) de preços, mostra seus dados na tela, aplica o desconto<br>
que você desejar e após aplicar o desconto, reescreve os antigos valores pelos novos e escreve uma nova<br>
planilha **.csv** e joga para a pasta de documentos da sua máquina.

## Como rodar o programa:
1. Há uma pasta chamada **testes-arquivo**, nela contém uma planilha de testes que pode ser usada para você testar e observar;
2. Copie o caminho desse arquivo **.csv** e compile o programa;
3. Após compilar ele na sua máquina, ele primeiro irá pedir para que você insira o caminho do arquivo válido, ou seja: <br>
/home/nome-usuario/nome-do-arquivo.csv, isso tudo dependerá de qual sistema operacional você usa;
4. Após colocar o arquivo (de preferência o **.csv** dentro da pasta **testes-arquivo**) ele irá pedir para que você digite o desconto que você desejar;
5. Digitando-o você pode clicar no botão de **"Calcular Preço"**.<br>
Ele irá fazer todo o cálculo, escrever em um novo arquivo e jogar na sua pasta de **Documentos**.
